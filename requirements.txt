# SafeFall AI - requirements.txt for GitHub repo / Streamlit Cloud
# ============================================================
# This is DIFFERENT from your local requirements.txt:
#   - opencv-python-headless (not opencv-python) — Streamlit Cloud's
#     containers have no display server, plain opencv-python throws
#     "ImportError: libGL.so.1" on that platform.
#   - torch is pulled from the CPU wheel index — Streamlit Cloud has
#     no GPU, and pulling a CUDA build would just waste build minutes
#     and fail or bloat the slug for nothing.
#
# pip supports --extra-index-url as a line inside requirements.txt,
# and Streamlit Cloud runs `pip install -r requirements.txt` directly,
# so this file works as-is for both local dev and deployment.

--extra-index-url https://download.pytorch.org/whl/cpu
torch
